# 柚柚今天学什么

一个纯静态、手机优先的「宝宝启蒙打卡」工具。**数据只存在你自己的浏览器里**（localStorage），不经过任何服务器。

英语启蒙排在第一位，每天固定；其余资源（思维机、识字、中文绘本）靠模板错开交替。打开就是今天该做什么、几点做、读哪一本。

主打三件事：

1. **周期模板**：计划条目按周重复，例如「每周一、周五做团队学习」。
2. **清单延续**：把 100 项内容一次性贴进去，系统连续 50 周自动切片，每天带具体内容。
3. **自动结转**：当天没勾完的事项，第二天自动出现在「顺延事项」里，直到你完成或主动放弃。

外加一个**周表**：把一周 7 天的时间点排成一张表，直接在上面打卡。

内置一份开箱即用的 **「宝宝启蒙打卡计划」**（设置 → 预设计划 → 一键载入），见文末第九节。

## 一、部署到 GitHub Pages

### 方式 A：网页上传（最简单，不用命令行）

1. 在 GitHub 新建一个仓库，例如 `baby-plan`（**不要**勾选 Add README / .gitignore / license，保持空仓库）。
2. 把本目录下**全部文件**上传到仓库根目录（包含 `.nojekyll`、`sw.js`、`manifest.webmanifest`、`icons/`、`css/`、`js/`、`index.html`）。
   - 注意：`.nojekyll` 是隐藏文件，用拖拽上传时记得勾选显示隐藏文件；它用来关闭 Jekyll 处理，避免 `_` 开头的文件被忽略。
3. 进入仓库 **Settings → Pages**：
   - Source 选 `Deploy from a branch`
   - Branch 选 `main`，目录选 `/ (root)`
   - 保存，等 1–2 分钟。
4. 访问 `https://<你的用户名>.github.io/plan/`。

### 方式 B：命令行

本目录**已经建好本地仓库并完成首次提交**（20 个文件，`.gitignore` 已排除 `build/shots/` 等截图），所以只需要接远程和推送：

```bash
git remote add origin https://github.com/<你的用户名>/baby-plan.git
git push -u origin main
```

首次推送会弹浏览器让你登录 GitHub（本机已有 Git Credential Manager），登录后会自动记住。

之后再改代码，就是常规三步：

```bash
git add -A
git commit -m "说明这次改了什么"
git push
```

然后到 Settings → Pages 里开启即可。

### 关于 Actions 自动部署

**不需要**。上面这种「分支部署」本身就是每次 push 后自动重建，1 分钟左右生效。

唯一例外：如果你在 Settings → Pages 里把 Source 改成 `GitHub Actions`，那么必须提交一份 `.github/workflows/pages.yml`（`actions/configure-pages@v5` 不能代为开启 Pages，用 `enablement: true` 会因 `GITHUB_TOKEN` 权限不足直接失败——必须在设置里先手动把 Source 指过去，工作流才能跑通）。

## 二、装到手机桌面（推荐）

部署好之后用手机浏览器打开链接：

- **iPhone / Safari**：点底部分享 → 「添加到主屏幕」。
- **Android / Chrome**：点右上角菜单 → 「安装应用」或「添加到主屏幕」。

添加后会以独立 App 的样子全屏打开，没有浏览器地址栏，断网也能用（有 Service Worker 缓存）。

## 三、数据说明（重要）

数据保存在当前浏览器的 `localStorage` 里，键名 `chengming.plan.v1`。

**会丢数据的情况**：清除浏览器数据、卸载浏览器、换手机、换浏览器、无痕模式、iOS 长期不用被系统清理。

所以请养成习惯：**每周去「设置 → 导出备份」存一份 JSON**。换设备时用「导入恢复」把 JSON 导回去即可（可选覆盖或合并）。

另外还有「导出为文本」，生成 Markdown 格式的清单，方便贴到笔记里或打印。

## 四、怎么用

### 1. 先建清单

「清单」→ 新建清单，把内容一行一条贴进去：

```
需求评审流程与判据
竞品功能拆解
…
```

粘贴时输入框下方会实时显示有效条数。空行、重复项会自动清理。

### 2. 再建模板

「计划」→ 新建模板，设置：

| 项 | 说明 |
| --- | --- |
| 排期方式 | **每周指定几天**（如周一、周五）／**每天**（可排除周末） |
| 推进基准 | **按周推进**：同一周内不同日子各有内容，跨周连续不重复<br>**按工作日推进**：只在工作日消耗，周末冻结 |
| 分组 | 每天几条 × 每条含几项 |
| 时间段 | 给每条排上具体时间，如 `10:30-11:30`。**可留空**；填了会显示在任务卡上，并计入回望时长 |
| 内容来源 | **固定内容**（每天都一样）／**引用清单**（按顺序延续）／**每 4 周随机**（同周期内不重复） |

举例：团队学习 100 项，排 50 周，每周一/五 10:30-11:30

- 排期方式：每周 → 勾选周一、周五
- 推进基准：按周推进
- 条目数：每天 1 条，每条 1 项
- 时间段：第 1 条填 `10:30-11:30`
- 内容来源：引用清单 → 团队学习清单

设置完成后，「清单」页会显示「100 项 · 已排 N 项 · 约至 2027年11月8日（50 周）· 每周消耗 2 项」，超过 100 项后自动回绕到第 1 项。

**时间段怎么填**（几种写法都认）：

| 输入 | 结果 |
| --- | --- |
| `10:30-11:30` | 1 小时 |
| `9:00-18:00` | 自动补零为 `09:00-18:00`，9 小时 |
| `10.30-11.30` | 句点当冒号 |
| `10:30~11:30` | 波浪号当连字符 |
| `10：30-11：30` | 全角冒号也认 |
| `14:00` | 只写开始时间，不计时长 |

「每日条目数」填几，就出现几个时间段输入框——比如每天 2 条，可以分别设 `09:00-10:00` 和 `14:00-15:30`。改条目数时输入框会自动增减，已有的时间不会丢。

如果某一天临时要挪时间，点事项正文 → 「当天时间」，只覆盖那一天，不影响模板。

### 3. 每天用

「今日」页顶部会显示一句金句，下面按时间顺序排当天的事项，分三组：

- **顺延事项**（朱砂色标签）：以前没做完的，带「昨日」或「顺延 N 天」标记
- **原生分组**：今天模板排出来的
- **临时添加**：手动加的一次性事项

每张卡片左侧有时间徽标（如 `10:30–11:30`）。**到了开始时间还没做、且没超过 2 小时**的，时间会变朱砂色提醒你；超时就恢复灰色，避免整页飘红。

进度卡上会顺带显示「约 2 小时」——这是当天排期的总时长，用来判断有没有排过头。分组标题写了分组名，卡片里就不重复显示标签了；只有顺延到别的日子的条目才带自己的分组名。

点左侧圆圈勾选完成。点事项正文可以：

- 修改内容（只影响当天）
- 改当天时间（只影响当天）
- 今日移除（只影响这一天，之后照常排期）
- 不再跟进此项（从顺延队列里彻底消失）

### 3.1 月历

「今日」页右上角的日历图标打开月历，可以一眼看整个月的完成情况：

- 日期下方的小圆点：**实心**＝当天全部完成，**空心**＝完成了一部分，**浅灰**＝有安排但没完成
- 今天是深色方块，正在查看的日期有描边，休息日右上角标「休」
- 点任意一天直接跳到那天查看；顶部左右箭头翻月，覆盖周一为第一列的完整 6 行网格
- 底部三个数字：本月完成项数 / 本月投入小时数 / 本月完成率

从别的日期回到今天，用右上角的返回箭头（或月历里的「回到今天」）。离开今天时标题旁会出现「非今天」小标签，避免看错日期勾错完成。

### 3.2 周表

底部第二个标签「周表」，把一周 7 天按时间点摊开看 —— 这是「每天几点做什么」最直观的地方。

- 顶部三个数字：本周总时长 / 总项数 / 完成率
- 每天一张卡：左边是时间点（`17:30`），右边是内容，最左边可以直接点勾打卡
- 点日期抬头（如「周一 11/23」）跳到那一天的详情
- 左右箭头翻周，翻走后会多出一个「回到本周」
- 只显示模板排出来的骨架，**不掺顺延事项** —— 顺延只在「今日」里出现，免得周表被历史欠账糊住
- 标记为休息的日子显示「休息」，且不计入完成率

### 4. 回望

「回望」页从上到下依次是：

1. **四个关键指标** —— 近 30 天完成率、连续达标、全清日、累计完成
2. **清单完成度** —— 每个清单完成了多少，如 `51/100`，带进度条。点进去能看到逐条明细，已完成的标绿并显示它是哪天被排到的
3. **累计投入** —— 每个模板累计完成了多少次、总共投入多长时间（按时段自动累加），如「日常推进 26 次 · 12 小时 40 分」。连续几天全做完的模板会多一个「连 N」小徽标
4. **近 4 周投入** —— 柱状图，看时间投入的走势
5. **近 8 周节奏** —— 热力图，颜色越深完成越多
6. **今日复盘** —— 今天最有价值的一件事 / 卡住的地方 / 精力打分
7. **顺延中的事项** —— 当前欠账，可一键放弃

> 时长统计的前提是给分组配了时间段。没配时间的计划会计入「次数」但不计入「时长」。

### 5. 金句

首页每天自动换一句，内置 100 条。同一天刷新不变，次日自动换。

- **点首页的金句** → 换一句 / 恢复今日默认 / 进金句库
- **设置 → 每日金句** → 开关显示、管理金句库、换今天的金句
- **金句库**：一行一条，可整库替换成自己的句子。清空内容会退回内置 100 条

想永久改掉内置文案，也可以直接编辑 `js/quotes.js`（记得把 `sw.js` 的 `CACHE` 版本号 +1）。

## 五、目录结构

```
.
├── index.html              # 入口
├── manifest.webmanifest    # PWA 配置
├── sw.js                   # Service Worker（离线缓存）
├── .nojekyll               # 关闭 GitHub Pages 的 Jekyll

├── js/
│   ├── quotes.js           # 内置 100 条金句（可改）

│   ├── favicon.svg
```

全部路径都是相对路径（`./`），所以放在仓库子目录（如 `/<仓库名>/`）也能正常工作。

## 六、本地调试

因为用了 Service Worker 和 fetch，不能直接双击 `index.html`（`file://` 协议下 SW 不生效），需要起一个本地服务：

```bash
# Python
python -m http.server 8899

# 或 Node
npx serve .
```

然后打开 `http://127.0.0.1:8899/`。

改完代码后如果页面没变化，是 Service Worker 缓存，硬刷新（Ctrl/Cmd + Shift + R）或在 DevTools → Application → Service Workers 里点 Unregister。

改配色改 `css/app.css` 顶部的 CSS 变量：

```css
:root {
  --paper:   #F6F4EF;  /* 纸底 */
  --ink:     #22201D;  /* 墨色正文 */
```

## 九、宝宝启蒙打卡计划（内置预设）

「设置 → 预设计划 → 载入宝宝启蒙打卡计划」，一次性铺好 9 份清单 + 7 个模板 + 361 条内容。

### 时间盘算

工作日只有 2 小时可用，所以按「饭前半小时 + 饭后一个半小时」切：

| 时间 | 内容 | 时长 |
| --- | --- | --- |
| 17:30–17:50 | 大猫分级 2 本（家长读、宝宝指图） | 20 分 |
| 17:50–18:00 | 斑马配套绘本 1 本（跟读） | 10 分 |
| 18:00–18:30 | 晚餐 | — |
| 18:30–18:40 | 斑马英语课程（平板） | 10 分 |
| 18:40–19:00 | 小小优趣英语动画 | 20 分 |
| 19:00–19:30 | 饭后自由 / 缓冲（吃晚了就用这段） | — |
| 19:30–20:00 | 主项：思维机（一三五）／识字（二四六） | 30 分 |
| 20:00–20:30 | 中文绘本 1 本 | 30 分 |
| 20:30–21:30 | 洗漱、睡前 | — |

合计 **120 分钟**，其中英语 60 分钟（一半），中文 60 分钟。周末多一段早上 09:00–10:00 的晨读加量，全天约 150 分钟。

### 7 个模板怎么分工

| 模板 | 排期 | 挂的清单 |
| --- | --- | --- |
| ① 英语绘本 · 工作日饭前 | 周一–周五 | 大猫（2 本/天）、斑马绘本（1 本/天） |
| ② 英语屏幕 · 每天晚饭后 | 每天 | 斑马英语课程、小小优趣 |
| ③ 思维机 · 隔天三科 | 一、三、五 | 思维卡、语文卡、英语卡（各 1 组） |
| ④ 识字 · 隔天一本 | 二、四、六 | 小羊上山 |
| ⑤ 中文绘本 · 每天一本 | 每天 | 科普 / 数学 / 情感 三科交替 |
| ⑥ 周末晨读加量 | 六、日 | 固定内容（复读 + 中文精读） |
| ⑦ 周日复盘 · 回看一周 | 周日 | 固定内容（抽字卡、重做错卡） |

「隔天」不靠系统开关，而是拆成 ③（一三五）和 ④（二四六）两个模板占同一个 19:30 时段 ——
两条线自然错开，谁也不会撞车。

### 九份清单的续航

| 清单 | 条数 | 消耗速度 | 约可支撑 |
| --- | --- | --- | --- |
| 大猫分级绘本 | 60 本（6 个级别 × 10 本） | 10 本/周 | 6 周 |
| 斑马配套绘本 L1/L2 | 40 本 | 5 本/周 | 8 周 |
| 斑马英语课程 S1 | 70 节（10 周 × 7） | 7 节/周 | 10 周 |
| 小小优趣动画片单 | 39 条 | 7 条/周 | 5 周 |
| 思维机 · 思维卡 | 20 组 | 3 组/周 | 6 周 |
| 思维机 · 语文卡 | 16 组 | 3 组/周 | 5 周 |
| 思维机 · 英语卡 | 16 组 | 3 组/周 | 5 周 |
| 小羊上山识字 | 40 册（4 级 × 10 册） | 3 册/周 | 13 周 |
| 中文绘本 | 60 本（科普/数学/情感各 20） | 7 本/周 | 8 周 |

走完一轮会自动回绕到第 1 条。届时去「清单」里追加下一个级别（比如大猫 2 级②、3 级），续航就续上了。
清单条目里的编号（`大猫预备级① 第03本`）对应你手上那套书的顺序，按顺序摆好即可。

### 载入后会自动做的两件事

- 周期基准日锚到**本周一**，内容从第 1 条开始，不会从中间截断
- 本周一到今天之前的日子标记为休息 —— 周表照样能看到排期，但不会一上来就欠你 8 项
